# 情侣 app 市场调研（2026-10-22）

> 目的：看清市面上同类产品都在做什么，判断哪些值得抄、哪些是坑。
> 方法：抓取并统计 **恋爱记**（App Store 描述，中国市场代表）+ **Bonobology「21 Best Apps for Couples 2025」**（英文市场合集）的正文关键词频次；
> 局限：微光 / QQ 情侣空间 的百科页反爬抓不到，未纳入；频次只代表"提及热度"，不代表实际留存效果。

## 三、值得考虑的候选（按性价比排序）

| 候选 | 价值 | 成本 | 我的判断 |
|---|---|---|---|
| **回忆卡接真实照片 + 每日换一张** | 高（把已有照片变成"每天的小惊喜"）| 低（数据已有）| 正在做，做完就是差异化 |
| **相册分组 / 标签** | 中（照片多了必然需要）| 中（表已建，只需 UI）| 照片攒到几百张再做不迟 |
| **共同记账（极简版）** | 中高（真实痛点，市场空白）| 中（一张表 + 一个页面 + 月度汇总）| 唯一"市场有需求但我们完全没有"的实用功能 |
| **情侣问答 / 默契测试** | 中（好玩，能制造话题）| 中（要写题库内容）| 内容是坑，先做 10 题试试可以 |
| **恋爱日记（图文）** | 高（恋爱记主打）| 中高（写作体验要求高，容易做成半成品）| 和照片功能重叠，优先级低于记账 |
| 每日打卡 / 连续天数 | 中（市场最热）| 低 | **建议不抄**，见下文 |

## 四、明确不建议抄的（附理由）

1. **每日打卡 / 连续天数 / 等级 / 亲密度积分**
   这类是"留存机制"，靠制造损失厌恶（断签掉级）把人拉回来。PRD 里明确判断"两人不会坚持每日使用"，靠愧疚感驱动的功能最后只会让 app 变成负担。我们改用**有用的推送**（纪念日、对方的心愿）替代。

2. **虚拟宠物 / 共养小游戏**
   工作量最大、内容消耗最快，且和"回忆过去 + 期待未来"的定位无关。

3. **位置共享 / 实时定位**
   隐私优先原则（PRD §7）直接冲突，且容易演变成监视工具。

4. **关系咨询 / 课程 / 每日一问（Paired、Lasting 那套）**
   这是内容公司的生意，不是两个人的私人空间。硬做会得到一堆没人读完的文案。

## 五、一句话结论

市面上产品的主流方向是**"平台化 + 内容化"**（做社区、做课程、做游戏、做留存机制），而我们的定位是**"两个人的私人小家"**：不社交、不打卡、不评分、数据私有。
所以正确的抄法是：**只抄"能减轻你们负担"或"能制造真实回忆"的功能**（记账、相册、日记），不抄"制造焦虑"的功能（打卡、等级、连续天数）。
